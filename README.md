# midi-catalog

Piece catalog for the MIDI Player app, served by GitHub Pages:
`https://defiance99.github.io/midi-catalog/catalog.json` and `midi/*.mid`.

Generated by `flutter/tool/catalog/build_catalog.dart` in the app repository —
do not edit by hand; rebuild and replace the files instead.

## Sources and licences

All MIDI files come from the [Mutopia Project](https://www.mutopiaproject.org),
sheet music typeset in LilyPond by volunteers. Each piece keeps its own licence,
listed in `catalog.json` (`license`, `typesetBy`, `sourceUrl`):

- Public Domain
